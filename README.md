# Парсинг вакансій аналітиків з robota.ua
 
Збір і аналіз відкритих вакансій для Data Analyst, щоб зрозуміти,
які навички найчастіше вимагають роботодавці в Україні.
 
## Дані123
 
Джерело: robota.ua, розділ «Аналітика».
Період збору: березень 2026.
Обсяг: 480 вакансій.
Метод: парсинг HTML через requests + BeautifulSoup.
 
## Що всередині
 
- `scraping.ipynb` - збір даних із сайту
- `analysis.ipynb` - очистка, аналіз, візуалізації
- `data/vacancies.csv` - зібраний датасет
 
## Основні висновки
 
- SQL згадується у 78% вакансій - найчастіше з усіх навичок
- Python вимагають у 52%, переважно в middle+ позиціях
- 41% вакансій пропонують віддалений формат

## Як запустити
 
1. Відкрити `scraping.ipynb` у Google Colab
2. Виконати комірки послідовно
3. Датасет збережеться в `data/`

Python, pandas, BeautifulSoup, requests, matplotlib
